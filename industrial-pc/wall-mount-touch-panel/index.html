WALL-MOUNT TERMINAL

Wall-Mount Touch Panel

White wall-mounted touch terminal shown running Windows and Android builds, with a slim rear housing that sits flat against the wall.

A slim white touch terminal for wall mounting in corridors, lift lobbies and reception areas. The reference units run the same hardware in two platform builds — a Windows desktop image and an Android appliance image — so the software route is chosen after the application is defined. The rear housing carries the computing module and antenna mounts and keeps the visible front face to the display only.

All industrial PCs

Interfaces on this unit

Interfaces listed below are the ones visible on the reference photos. Port counts and levels for your build are confirmed in the specification review.

  • Wide-format touch display
  • HDMI / VGA video from the computing module
  • USB touch and peripheral ports
  • RJ45 network
  • Wi-Fi antennas (rear mount)
  • Flat wall-mount rear housing

Configuration options

Points to agree before a quotation. Final availability, interfaces and ratings depend on the selected platform.

  • Screen size and touch technology
  • Windows or Android platform image
  • Brightness and surface treatment
  • Enclosure colour and front branding
  • Wall bracket and cable-exit planning
  • Optional camera or NFC module space
