How to specify an industrial computer

Four questions that shape the platform, the I/O set and the mechanical design.

1. Software first

List the operating system, runtime, drivers and CPU class your application actually needs.

2. I/O and expansion

Count the serial ports, LAN ports, USB devices and expansion slots the installation requires.

3. Environment

Record ambient temperature, dust, vibration, power input range and available mounting space.

4. Lifecycle

Agree the supply period, revision control and what happens when a component reaches end of life.
