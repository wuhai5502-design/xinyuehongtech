About Xinyuehong

Xinyuehong is a Shenzhen-based team working on self-service kiosk terminals and the industrial computers that run them. This page explains how projects are handled and what to prepare before you write to us.

WHO WE ARE

A hardware partner for self-service work

Xinyuehong works on customer-facing self-service hardware: ordering terminals, payment and check-in kiosks, ticketing machines, information points, and the fanless computers, boards, panel PCs and gateways that sit inside them.

Most conversations start with a problem rather than a product: a queue that grows too long, a counter that cannot stay staffed, or a task that employees repeat hundreds of times a day. We work backwards from that task to decide screen size, enclosure style, peripheral set and computing platform.

Every project is built to a written specification. Interfaces, finishes, quantities, power requirements and delivery expectations are confirmed on both sides before production starts, so everyone knows what the finished unit is supposed to be.

What we work on

Four areas that decide whether a terminal survives contact with real users.

01

Requirement review

Your application flow, software stack and venue constraints are reviewed first, and anything that will not work is flagged before a quotation is issued.

02

Enclosure design

Cabinet form factor, material, finish, colour, logo treatment, service access and cable routing are considered as one mechanical package.

03

Peripheral integration

Printers, scanners, cameras, card readers and payment-device mounting are planned with the enclosure instead of being added afterwards.

04

Platform selection

Fanless box PCs, boards, panel PCs and gateways are matched to the operating system, I/O count and installation environment.

How a project runs

The same four stages whether you order a single unit or a repeat batch.

1. Send the brief

Describe the application, estimated quantity, target environment and any software that must run on the unit.

2. Confirm the specification

Screens, peripherals, interfaces, finishes, power and mounting are written down and agreed by both sides.

3. Review before volume

Where a project justifies it, drawings or a sample unit are evaluated before repeated production.

4. Production and repeat orders

Agree in advance which parts stay stable across batches and how later changes are handled.

Questions we are asked first

What should I prepare before requesting a quotation?
A short description of the task, the software or POS the unit must run, indoor or outdoor placement, required peripherals, estimated quantity and target delivery window. Drawings help but are not required for a first discussion.
Can you work with software we already use?
Yes. Send interface, driver and SDK documentation early. Checkout flows that involve card payments usually stay with your own certified payment provider; we plan the physical mounting and cabling for that device.
What quantity does a custom project need?
There is no fixed number. Tooling and setup effort differ between a modified existing enclosure and a fully new one, so the practical minimum is discussed per project and written into the quotation.
