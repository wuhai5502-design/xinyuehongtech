Questions about the datasheets

Are the specifications in the datasheets final?
They describe the reference build. Screen size, module mix, electrical ratings and certification scope are confirmed in writing for each project, so a datasheet is a starting point for a specification conversation rather than a fixed order code.
Can you send a datasheet for a custom configuration?
Yes. Send the module list you need and we will issue a configuration datasheet with the same structure, showing what fits the standard cabinet and what requires a new enclosure.
Do you provide 3D CAD or dimension drawings?
Dimension drawings and STEP files are available for qualified projects, normally after the enclosure and module list are agreed. Ask for them with the datasheet reference.
