Before you request a quote

How will visitors identify themselves?
Choose the reader set that matches the venue: ID card scanner for clinics and government counters, passport MRZ reader for hotels, QR or booking-reference entry for visitor management. The reader is fixed before the cabinet is drawn, because it changes the deck layout.
Is document capture or printing necessary?
Both are optional. A receipt printer covers registration slips and queue numbers; a document scanner is added where the venue needs a copy of an ID or a signed form. Each adds a module bay and changes the service access.
Which existing booking or management system must connect?
The kiosk exposes the readers and the printer to your application through standard interfaces, so the booking system stays where it is. Send the integration method it supports — API, local agent or browser session — before the platform is specified.
